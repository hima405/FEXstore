# FEX Store

A branded mobile phone storefront website for FEX Store in Guwahati, Assam.

## Local development

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Notes

This project is built for a local electronics shop experience with product categories, customer reviews, service information, and contact actions.
